Questions

The short answers.

Can ACE build its own code platform?

Yes. Pick the "My own code platform" starter and ACE builds a working code playground: an editor, a Run button, a live preview and a console, which you can then keep extending. Platforms that need servers, user accounts or databases can be written too, but you'd host those yourself.

Which languages can it run?

The live preview runs web code: HTML, CSS and JavaScript, plus libraries loaded from public CDNs. ACE also writes Python, Java, C++, C#, Go, SQL and more, and tells you how to run them on your computer.

What powers ACE?

ACE runs on Claude, the AI made by Anthropic. Your messages and your project's files go to Claude, and its answers come back to this page.

Does it cost anything?

There's no separate fee. ACE uses your own Claude account, so messages count toward your Claude plan's usage, the same as chatting on claude.ai.

Where are my projects saved?

In the browser you're using. Download a project as a .zip to keep a copy or move it to another device. Clearing your browser data deletes saved projects.

Can I share ACE with friends?

Yes, from the Share menu on this page. Each person builds with their own Claude account and has their own projects.

What will you build first?

Start with a game, a tool, a website or your own code platform.
